# Описание:

Лёгкая утилита для автоматизации, заточена под Arch Linux. Вдохновляется опытом управления приложениями на macOS. Написано для себя с использованием ИИ.
Программа позволяет устанавливать ".deb" пакеты и ".tar.gz" архивы в изолированные папки внутри "~/Applications".


## Как скачать и установить:

Откройте терминал и выполните следующие команды:

git clone https://github.com/d33m11urge/linapp.git
cd linapp
chmod +x install.sh && ./install.sh

## Гайд по использованию:

1. Нажмите ПКМ по любому .deb или .tar.gz файлу, выберите "свойства", "открыть с помощью" или что-то в этом роде
2. Выберите в списке "Linapp Installer" и сделайте его программой по умолчанию для этого типа файлов.
3. В следующий раз можно просто запускать файл двойным кликом.
4. Откроется окно Dolpin. Нужно будет перетащить папку приложения в папку Applications
5. Двойной клик по "Eject_Installer.sh". Окно закроется, временные файлы удалятся, а иконка приложения появится в меню пуск.

## Удаление приложений:

Достаточно просто удалить папку программы из ~/Applications и всё готово. А меню пуск отчистится при следующем запуске системы или обновлении кеша. (секретная комманда если хочется срочно убрать иконку из меню пуск: update-desktop-database ~/.local/share/applications && kbuildsycoca6 2>/dev/null || kbuildsycoca5 2>/dev/null || true)
